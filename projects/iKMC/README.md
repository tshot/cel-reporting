## File structure on server

```
/var/www/projects/iKMC/
├── sync_config.php          ← credentials + table map (DO NOT commit)
├── sync.php                 ← CLI runner
├── config.php               ← (existing iKMC project config)
```

## Setup

### 1. Install the sqlsrv PHP extension (if not present)

```bash
php -m | grep sqlsrv   # check first

# Ubuntu/Debian
curl https://packages.microsoft.com/keys/microsoft.asc | apt-key add -
apt-get install php8.x-sqlsrv php8.x-pdo-sqlsrv
```

### 2. Deploy files

```bash
# Copy Sync classes
cp Sync/* /var/www/projects/iKMC/Sync/

# Copy runner and config template
cp sync.php      /var/www/projects/iKMC/
cp sync_config.php /var/www/projects/iKMC/

# Fill in credentials
nano /var/www/projects/iKMC/sync_config.php
```

### 3. Configure sync_config.php

Fill in MSSQL server, database, credentials.
Add one entry per table to the `tables` array.

### 4. Test with dry run

```bash
php /var/www/projects/iKMC/sync.php --dry-run
```

### 5. Run live

```bash
php /var/www/projects/iKMC/sync.php
php /var/www/projects/iKMC/sync.php --table=patients   # one table
```

### 6. Schedule (cron)

```bash
crontab -e

# Every night at 2am, log to file
0 2 * * * php /var/www/projects/iKMC/sync.php \
    --log=/var/log/ikmc_sync.log 2>&1
```

## Sync modes

| Mode           | SQL used                          | Use when                        |
|----------------|-----------------------------------|---------------------------------|
| `upsert`       | INSERT ... ON DUPLICATE KEY UPDATE| Safe default — re-runnable      |
| `replace`      | REPLACE INTO                      | Full refresh, PK must exist     |
| `insert_ignore`| INSERT IGNORE                     | Append-only, never overwrite    |

# iKMC — MSSQL → MySQL Sync Tool

## Overview

A PHP CLI tool that syncs tables from a remote Microsoft SQL Server database
to a local MySQL/MariaDB database. Built for the iKMC project under the CEL
reporting engine framework.

**Location on server:** `/var/www/projects/iKMC/`

---

## Project Structure

```
projects/iKMC/
├── sync.php              # CLI entry point
├── sync_config.php       # Connection credentials and table map (NOT in git)
├── composer.json         # PSR-4 autoloader for CEL\Projects\IKMC namespace
├── vendor/               # Generated by composer dump-autoload
└── Sync/
    ├── MssqlSyncClient.php   # Core sync engine
    ├── SyncResult.php        # Per-table result object
    └── Logger.php            # CLI/file logger
```

## Usage

```bash
# Sync all configured tables
php sync.php

# Sync one specific table (by dst name)
php sync.php --table=iKMCv2_EligibilityRegistration

# Dry run — count rows without writing
php sync.php --dry-run

# List all tables in MSSQL database
php sync.php --list-tables

# List only whitelisted tables (set 'discover' in sync_config.php)
php sync.php --list-tables

# List specific tables on the fly
php sync.php --list-tables --tables=dbo.eligibility,dbo.patients

# Show MSSQL server version
php sync.php --version

# Generate MySQL CREATE TABLE SQL from MSSQL table structure
php sync.php --generate-schema=dbo.eligibility,iKMCv2_EligibilityRegistration > /tmp/eligibility.sql

# Full production run with logging and email
php sync.php \
  --log=/var/log/ikmc_sync/sync_$(date +%Y-%m-%d).log \
  --error-log=/var/log/ikmc_sync/errors_$(date +%Y-%m-%d).json \
  --summary-email=amit.tandon@celworld.org
```

## Email Notifications

Summary email is sent after every run via SMTP. Email subject indicates status:
- `iKMC Sync OK — 2026-04-17` — all rows written successfully
- `iKMC Sync COMPLETED WITH ERRORS — 2026-04-17` — some rows failed

Email body contains: tables synced, rows fetched/written/errors, duration,
first 20 failed rows inline, and path to full error log.

### SMTP Configuration

Email is sent via direct PHP SMTP (no system MTA required). `mail()` was tried
first but failed because no MTA is installed on the server.

Gmail is used as the SMTP relay:
- **Host:** `smtp.gmail.com`
- **Port:** `587` (STARTTLS)
- **Auth:** Gmail App Password (16-character, not the Gmail login password)

To get an App Password:
1. Go to https://myaccount.google.com/security
2. Enable 2-Step Verification if not already on
3. Search for "App Passwords" → Create → name it "iKMC Sync"
4. Copy the 16-character password — shown only once

Add to `sync_config.php`:
```php
'smtp' => [
    'host'      => 'smtp.gmail.com',
    'port'      => 587,
    'username'  => 'your.gmail@gmail.com',
    'password'  => 'xxxx xxxx xxxx xxxx',  // 16-char App Password
    'from'      => 'your.gmail@gmail.com',
    'from_name' => 'iKMC Sync',
],
```

## sync_config.php — Table Map

Each entry in the `tables` array defines one table to sync:

```php
[
    'src'      => 'dbo.eligibility',              // MSSQL table (schema.table)
    'dst'      => 'iKMCv2_EligibilityRegistration', // MySQL table
    'pk'       => 'primary_key_column',           // PK for upsert
    'order_by' => 'primary_key_column',           // required for chunked fetch
    'map'      => [                               // optional column rename map
        'mssql_col' => 'mysql_col',
    ],
    'where'    => "status = 'active'",            // optional WHERE clause
],
```

**Currently configured tables:**
- `dbo.eligibility` → `iKMCv2_EligibilityRegistration`

**discover whitelist** — limits which tables `--list-tables` shows:
```php
'discover' => [
    'dbo.eligibility',
    // add more as needed
],
```

## Known Issues & Decisions

### PDO::ATTR_TIMEOUT
The `sqlsrv` PDO driver does not support `PDO::ATTR_TIMEOUT`. Using it causes:
`SQLSTATE[IMSSP]: An unsupported attribute was designated on the PDO object.`
**Fix:** Removed `ATTR_TIMEOUT` from sqlsrv connections. Use `LoginTimeout=30` in DSN instead.

### OFFSET FETCH requires ORDER BY
MSSQL's `OFFSET x ROWS FETCH NEXT y ROWS ONLY` syntax requires `ORDER BY`.
Without it: `SQLSTATE[42000]: Syntax error`.
**Fix:** Falls back to `ORDER BY (SELECT NULL)` when no `order_by` is configured.

### detectColumns schema prefix
`detectColumns()` was querying `INFORMATION_SCHEMA.COLUMNS WHERE TABLE_NAME = 'dbo.eligibility'`
(with schema prefix included), returning zero rows, causing empty INSERT SQL → MariaDB syntax error.
**Fix:** Strip schema prefix before querying — split on `.` to get schema and table separately.

### TrustServerCertificate
Remote MSSQL server uses a self-signed SSL certificate.
**Fix:** Added `TrustServerCertificate=yes` to DSN. Long-term: set up WireGuard VPN.

### MySQL table must exist before sync
`MssqlSyncClient` does not auto-create MySQL tables. Use `--generate-schema` to
generate `CREATE TABLE` SQL from the MSSQL structure, then run it in MySQL.
